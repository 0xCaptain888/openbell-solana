# OpenBell v0.4.0 — Live Judge and partner integration

Released: September 14, 2026

## Prize-critical upgrade

- Added a public, restricted Live Judge Run that performs a read-only Jupiter AAPLx route observation, creates an isolated Ed25519 policy, persists a task to Redis, runs strict evaluation, reads the result back, and returns task-specific notifications.
- Fixed the Judge route to AAPLx and a $10 maximum with `settle:false`, `recover:false`, five-minute expiry, idempotency, and a 20-second creation boundary.
- Added a production proof dashboard to the Demo with staged progress, task/hash copy controls, sanitized JSON, and explicit truth boundaries.
- Kept deterministic VERIFIED/BLOCKED/FROZEN fixtures separate from live production evidence.

## Integration surface

- Added `openbell-solana/api-client`.
- Added TypeScript declarations for the SDK, policy module, and HTTP client.
- Added OpenAPI 3.1 documentation.
- Added a runnable third-party trading-agent example.
- Added cursor pagination and idempotent task creation to the hosted operator API.
- Added publishable package metadata and an MIT license. The package remains GitHub-installable and is not claimed as published to npm.

## Verification

- 27 automated tests pass.
- CLI verifier, SDK demo, partner demo, JavaScript syntax checks, diff checks, and npm dry-run packaging pass.
- The browser Demo was inspected in a local mobile-width viewport; the production proof falls back to committed sanitized evidence when the serverless API is absent.
